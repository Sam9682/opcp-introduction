Landing Zone Manager

Intermediate 🇫🇷 Français

Objective

The Landing Zone Manager is the end-user portal for the OPCP platform. It allows each team, department or customer to deploy and manage their workloads autonomously, in a dedicated and isolated space.

Administrators provision users and give them access to the platform. Each user account relies on a dedicated realm in the underlying Keycloak instance, ensuring multi-tenant access isolation.

Prerequisites

  • Admin access to Landing Zone Manager
  • Default first-login password
  • Landing Zone Manager URL
  • User information to provision (name, first name, email)

Step 1: Access account management

Connect to the Landing Zone Manager with your admin privileges. Once logged in, navigate to the "Account management" section from the main menu.

Step 2: Create a new user account

Click the "+ Create new account" button and fill in the following information:

  • Name — Account name (organisation or project identifier)
  • Email — User's email address (also used as login)
  • First name — User's first name
  • Last name — User's last name

Step 3: Communicate first login credentials

Once the account is created, share the following information with the user:

  • URL — The Landing Zone Manager address
  • Login — The email address provided during account creation
  • Default password — The shared password for all first logins (set at deployment time)

Important: The default password is shared across all new accounts. It is set during platform deployment and must be communicated securely.

Step 4: First login

On their first login, the user:

  1. Connects with their email address and the default password
  2. Is immediately prompted to change their password to a personal and secure one

Keycloak mapping

The Landing Zone Manager has its own dedicated Keycloak stack. This instance is not federated with OPCP Core or CloudStore Keycloak.

Each account created in the Landing Zone Manager generates a dedicated realm in Keycloak, ensuring:

  • Independent authentication flow — Customisable configuration per account
  • Separate user bases — Complete user isolation between realms
  • Distinct role mappings — Per-realm permission management

Multi-tenant architecture: Realm-based Keycloak isolation ensures that no account can access the resources or users of another account. Each tenant operates in a completely segregated space.

Key takeaways

  • The Landing Zone Manager is OPCP's end-user portal for autonomous workload deployment.
  • Administrators create accounts and communicate first-login credentials.
  • Each user must change their password on first login.
  • The Landing Zone Manager uses its own Keycloak instance (not federated with OPCP Core or CloudStore).
  • Each account has a dedicated Keycloak realm ensuring full multi-tenant isolation.
