API Usage & Credential Management

Intermediate

Overview

OPCP exposes standard OpenStack APIs for managing your on-premise bare metal infrastructure programmatically. These APIs are accessible from the Project > API Access tab in the Horizon dashboard, which lists all available service endpoints.

In addition to the OpenStack APIs, OPCP provides dedicated CLI tools for platform management and diagnostics.

Reference: OVHcloud OPCP Getting Started Documentation

Available APIs

OPCP provides access to the following OpenStack service APIs:

Service API Purpose
Identity Keystone Authentication, authorisation, and service catalog
Compute Nova Instance (server) lifecycle management
Image Glance OS image management and discovery
Networking Neutron Network, subnet, port, and security group management
Bare Metal Ironic Bare metal node lifecycle and provisioning

All endpoint URLs are visible in Project > API Access within the Horizon dashboard.

CLI Tools

OPCP provides several command-line tools for platform management:

opcp-cli

The primary CLI tool for OPCP configuration and operations:

  • Declare and manage platform resources
  • Configure platform components
  • Perform operational tasks (LACP configuration, etc.)

Access is via the OOB (Out-of-Band) management network.

opcp-diag

Diagnostic tool for platform health assessment:

  • Produce a platform health state report
  • Extract logs for remote diagnosis by OVHcloud support

python-ironicclient

For direct bare metal node management via CLI:

# Install the Ironic client
pip install python-ironicclient

# List bare metal nodes
openstack baremetal node list

# Show node details
openstack baremetal node show $NODE_ID

# Manage node state transitions
openstack baremetal node manage $NODE_ID
openstack baremetal node provide $NODE_ID

Accessing the APIs

API access in OPCP follows the standard OpenStack authentication flow:

Authentication Flow

  1. Obtain a token — Authenticate against Keystone using your credentials (managed via Keycloak)
  2. Discover endpoints — The service catalog returned by Keystone lists all available API endpoints
  3. Make API calls — Use the token to authenticate requests to Nova, Neutron, Glance, or Ironic

Via Horizon Dashboard

Navigate to Project > API Access to:

  • View all service endpoint URLs
  • Download the OpenStack RC file (openrc) for CLI authentication
  • Access the service catalog

Via Command Line

Source the OpenRC file and use the standard OpenStack CLI:

# Source your credentials
source openrc.sh

# Verify authentication
openstack token issue

# List available services
openstack catalog list

Credential Management

Credentials in OPCP are managed through Keycloak (the embedded Identity and Access Management service):

  • User accounts — Created and managed in Keycloak
  • Roles and permissions — Defined at the project/domain level in Keystone
  • LDAP/AD integration — Optional connection to external identity providers (TCP/636 LDAPS)
  • Application credentials — Can be created in Keystone for service-to-service authentication

Credential Rotation

Regular credential rotation is recommended:

  • Admin accounts — Rotate every 30 to 90 days
  • Service accounts — Rotate every 90 to 180 days
  • Application credentials — Set appropriate expiry dates at creation

Key Takeaways

  • OPCP uses standard OpenStack APIs — Keystone, Nova, Glance, Neutron, and Ironic
  • All API endpoints are listed in Horizon under Project > API Access
  • opcp-cli is used for platform configuration and resource declaration
  • opcp-diag provides platform health diagnostics and log extraction
  • python-ironicclient enables CLI management of bare metal nodes
  • Authentication is managed via Keycloak with optional LDAP/AD integration
  • All management is done via the OOB (Out-of-Band) network
