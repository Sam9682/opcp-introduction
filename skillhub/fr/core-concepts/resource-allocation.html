Gestion des Ressources dans OPCP

L'allocation des ressources dans OPCP est gérée via les services OpenStack, chacun responsable d'un domaine de ressources spécifique. Puisque OPCP est une plateforme bare metal, les ressources correspondent au matériel physique plutôt qu'à des tranches virtuelles.

La plateforme fournit une interface unifiée (tableau de bord Horizon + API) pour gérer les ressources de calcul, réseau et stockage de votre baie sur site.

Référence : Documentation OVHcloud OPCP — Premiers pas

Services OpenStack pour la Gestion des Ressources

Type de Ressource Service OpenStack Ce qu'il Gère
Compute Nova + Ironic Provisionnement de serveurs bare metal, cycle de vie des instances, placement
Réseau Neutron Réseaux, sous-réseaux, ports, groupes de sécurité, IP flottantes, trunks
Stockage Bloc Ceph RBD Volumes blocs persistants attachés aux instances
Stockage Objet S3-compatible (CloudStore) Données non structurées : sauvegardes, logs, fichiers médias
Image Glance Images OS pour le déploiement bare metal

Ressources Compute (Nova + Ironic)

Le compute dans OPCP signifie des serveurs bare metal. Les ressources sont allouées en déployant des instances sur les nœuds disponibles :

  • Modèle d'allocation — Une instance par nœud physique (pas de surallocation puisque c'est du bare metal)
  • Placement — Nova place les instances sur les nœuds correspondant aux traits du flavor demandé
  • Quotas — Visibles dans Projet > Vue d'ensemble : instances max, vCPUs et RAM
# Vérifier l'utilisation actuelle des quotas compute
openstack quota show

# Lister les nœuds disponibles prêts pour le déploiement
openstack baremetal node list --provision-state available

Ressources Réseau (Neutron)

Neutron gère tout le réseau dans OPCP, et les switchs physiques sont auto-configurés depuis l'état OpenStack :

  • Réseaux et sous-réseaux — Réseaux logiques mappés sur des VLANs physiques
  • Ports — Points d'attachement réseau pour les instances
  • Groupes de sécurité — Règles de pare-feu appliquées au niveau du port
  • IP flottantes — Adresses IP accessibles depuis l'extérieur
  • Trunks — Connectivité multi-VLAN pour un seul port
# Lister les réseaux
openstack network list

# Créer un réseau
openstack network create mon-reseau

# Créer un sous-réseau
openstack subnet create --network mon-reseau --subnet-range 192.168.1.0/24 mon-sous-reseau

Ressources de Stockage

Stockage Bloc (Ceph RBD)

Volumes blocs persistants pour les instances, alimentés par Ceph :

  • Les volumes peuvent être attachés/détachés des instances
  • Les données persistent indépendamment du cycle de vie de l'instance
  • Répliquées dans le cluster Ceph pour la durabilité

Stockage Objet (S3-compatible CloudStore)

Stockage compatible S3 pour les données non structurées :

  • Endpoint de sauvegarde (TCP/443) — Stockage des sauvegardes d'infrastructure
  • Endpoint de métriques (TCP/443) — Stockage long terme des métriques
  • Accessible via les API et outils S3 standards

Gestion des Quotas

Les quotas dans OPCP définissent les ressources maximales disponibles pour un projet. Consultez-les dans Projet > Vue d'ensemble :

Catégorie Éléments de Quota
Compute Instances, vCPUs, RAM
Réseau IP flottantes, Groupes de sécurité, Réseaux, Ports
Stockage Volumes, stockage total (Go), snapshots

Puisque OPCP est sur site, les quotas représentent votre capacité matérielle physique. Contactez votre représentant OVHcloud pour discuter des ajustements de quotas.

Points Clés à Retenir

  • L'allocation des ressources dans OPCP est gérée via les services OpenStack : Nova/Ironic (compute), Neutron (réseau), Ceph RBD (stockage bloc), CloudStore (stockage objet)
  • L'allocation compute est bare metal — une instance par nœud physique, pas de surallocation
  • La configuration réseau dans OpenStack pilote automatiquement la configuration des switchs physiques
  • Le stockage bloc est fourni par Ceph RBD avec réplication pour la durabilité
  • Le stockage objet compatible S3 est disponible pour les sauvegardes et les métriques
  • Les quotas représentent la capacité physique et sont visibles dans Projet > Vue d'ensemble
