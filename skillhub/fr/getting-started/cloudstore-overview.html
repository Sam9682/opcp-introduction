Présentation de CloudStore

Intermédiaire 🇬🇧 English

L'analogie de l'entrepôt sécurisé

Imaginez que votre entreprise génère des montagnes de documents, photos, vidéos et fichiers de données chaque jour. Où stockez-vous tout cela ?

Pensez à CloudStore comme un entrepôt sécurisé et extensible pour vos actifs numériques — situé directement dans vos propres locaux. Tout comme un centre de stockage professionnel :

  • Il grandit avec vous — besoin de plus d'espace ? Il suffit de demander de la place supplémentaire. Aucune construction nécessaire.
  • Il est toujours accessible — le personnel autorisé peut récupérer des éléments à tout moment grâce à des outils S3-compatibles standards.
  • Il est géré professionnellement — l'installation gère la sécurité, la maintenance et la disponibilité. Vous vous concentrez sur votre activité.
  • Vos éléments restent sur site — les données ne quittent jamais vos locaux, garantissant une souveraineté totale.

CloudStore est le service de stockage objet S3-compatible d'OVHcloud au sein de la plateforme OPCP. Il fonctionne localement sur votre rack OPCP on-premise, vous permettant de stocker, organiser et récupérer tout type de données numériques via l'API S3 standard (compatible AWS SDK) — sans que vos données ne quittent jamais votre site.

Comment fonctionne CloudStore

Cas d'utilisation courants

CloudStore est suffisamment polyvalent pour répondre à de nombreux besoins métier. Voici les scénarios les plus courants :

Stockage de documents

Stockez contrats, rapports, tableurs et présentations dans un emplacement central accessible à toute votre équipe. Pensez-y comme un classeur partagé qui ne manque jamais de tiroirs et qui est accessible depuis n'importe quel outil S3-compatible.

Archives multimédia

Conservez de grandes collections d'images, vidéos et fichiers audio en toute sécurité et de manière organisée. Les équipes marketing, agences créatives et entreprises médias utilisent CloudStore pour maintenir leurs bibliothèques grandissantes sans se soucier du manque d'espace.

Données applicatives

Les applications logicielles génèrent des données en permanence — enregistrements utilisateurs, journaux de transactions, fichiers de configuration. CloudStore fournit un hébergement fiable pour ces données via l'API S3, garantissant que les applications peuvent lire et écrire des informations rapidement et en toute sécurité.

Sauvegardes

Créez des copies de sécurité de vos données métier critiques. Si quelque chose tourne mal avec vos systèmes principaux — panne matérielle, suppression accidentelle ou incident de sécurité — vos sauvegardes dans CloudStore vous permettent de récupérer rapidement, le tout sans que les données ne quittent vos locaux.

Caractéristiques spécifiques à OPCP

CloudStore sur OPCP possède des caractéristiques spécifiques qui le différencient de l'offre S3 cloud public. Comprendre ces points permet de conseiller les clients avec précision :

  • MonoAZ uniquement — CloudStore opère dans une seule zone de disponibilité (votre rack on-premise). Il n'y a pas de configuration multi-AZ.
  • Classe de stockage Standard uniquement — Seule la classe « Standard » est disponible. Il n'y a pas de classe « High Performance » sur OPCP.
  • Chiffrement SSE-C — Le chiffrement côté serveur avec clés fournies par le client est supporté. Le client gère et fournit la clé de chiffrement à chaque requête. Il n'y a pas de chiffrement au repos par défaut.
  • Versionnement via API — Le versionnement des objets est supporté et géré via l'API S3.
  • Pas de politiques utilisateur — Toutes les clés d'accès peuvent accéder à tous les buckets. Il n'y a pas de restriction par utilisateur par bucket.
  • Pas d'endpoint API de métadonnées — L'endpoint de métadonnées n'est pas disponible sur OPCP.
  • API S3-compatible — Entièrement compatible avec les AWS SDKs et les outils S3 standards.
  • Buckets locaux — Tous les buckets sont locaux à la plateforme OPCP, stockés on-premise sur le site du client.

Documentation officielle : Pour une liste complète des limitations et fonctionnalités supportées, consultez le guide des limitations S3 OPCP.

Pourquoi les clients choisissent CloudStore

  • Souveraineté totale des données — Les données restent sur VOS locaux, dans votre propre rack. Elles ne transitent jamais par des centres de données externes.
  • Compatibilité S3 — Utilisez les outils, SDKs et workflows existants conçus pour S3 sans modification.
  • Performance on-premise — Le stockage local signifie un accès à faible latence sans dépendance à internet.
  • Aucun matériel à gérer — OVHcloud gère l'infrastructure au sein de votre rack.
  • Prêt pour la conformité — Respectez les exigences strictes de résidence des données puisque les données restent physiquement sur site.
  • Capacité évolutive — Le stockage croît avec vos besoins dans la limite de la capacité physique du rack.

Points clés à retenir

  • CloudStore est un service de stockage objet S3-compatible fonctionnant localement sur votre rack OPCP.
  • Il gère documents, médias, données applicatives et sauvegardes via l'API S3 standard.
  • Les données ne quittent jamais vos locaux — souveraineté et conformité par conception.
  • Limitations clés : MonoAZ, classe Standard uniquement, chiffrement SSE-C (pas de chiffrement au repos par défaut), pas de politiques utilisateur.
  • Compatible avec les AWS SDKs et tout outil S3-compatible.
