Landing Zone Manager

Débutant 🇬🇧 English

Objectif

Le Landing Zone Manager est le portail utilisateur final de la plateforme OPCP. Il permet à chaque équipe, département ou client de déployer et gérer ses workloads de manière autonome, dans un espace dédié et isolé.

Les administrateurs provisionnent les utilisateurs et leur donnent accès à la plateforme. Chaque compte utilisateur repose sur un realm dédié dans l'instance Keycloak sous-jacente, garantissant une isolation multi-tenant des accès.

Prérequis

  • Accès administrateur au Landing Zone Manager
  • Mot de passe par défaut de première connexion
  • URL du Landing Zone Manager
  • Informations de l'utilisateur à provisionner (nom, prénom, email)

Étape 1 : Accéder à la gestion des comptes

Connectez-vous au Landing Zone Manager avec vos privilèges administrateur. Une fois connecté, naviguez vers la section « Gestion des comptes » (Account management) depuis le menu principal.

Étape 2 : Créer un nouveau compte utilisateur

Cliquez sur le bouton « + Créer un nouveau compte » et remplissez les informations suivantes :

  • Nom — Nom du compte (identifiant de l'organisation ou du projet)
  • Email — Adresse email de l'utilisateur (également utilisée comme identifiant de connexion)
  • Prénom — Prénom de l'utilisateur
  • Nom de famille — Nom de famille de l'utilisateur

Étape 3 : Communiquer les identifiants de première connexion

Une fois le compte créé, communiquez à l'utilisateur les informations suivantes :

  • URL — L'adresse du Landing Zone Manager
  • Identifiant — L'adresse email renseignée lors de la création
  • Mot de passe par défaut — Le mot de passe partagé pour toutes les premières connexions (défini au moment du déploiement)

Important : Le mot de passe par défaut est commun à tous les nouveaux comptes. Il est défini lors du déploiement de la plateforme et doit être communiqué de manière sécurisée.

Étape 4 : Première connexion

Lors de sa première connexion, l'utilisateur :

  1. Se connecte avec son adresse email et le mot de passe par défaut
  2. Est immédiatement invité à changer son mot de passe pour un mot de passe personnel et sécurisé

Mapping Keycloak

Le Landing Zone Manager dispose de sa propre stack Keycloak dédiée. Cette instance n'est pas fédérée avec le Keycloak d'OPCP Core ni celui de CloudStore.

Chaque compte créé dans le Landing Zone Manager génère un realm dédié dans Keycloak, garantissant :

  • Un flux d'authentification indépendant — Configuration personnalisable par compte
  • Des bases utilisateurs séparées — Isolation complète des utilisateurs entre realms
  • Des mappings de rôles distincts — Gestion des permissions propre à chaque realm

Architecture multi-tenant : L'isolation par realm Keycloak garantit qu'aucun compte ne peut accéder aux ressources ou aux utilisateurs d'un autre compte. Chaque tenant opère dans un espace complètement cloisonné.

Points clés à retenir

  • Le Landing Zone Manager est le portail utilisateur final d'OPCP pour le déploiement autonome de workloads.
  • Les administrateurs créent les comptes et communiquent les identifiants de première connexion.
  • Chaque utilisateur doit changer son mot de passe lors de la première connexion.
  • Le Landing Zone Manager utilise sa propre instance Keycloak (non fédérée avec OPCP Core ou CloudStore).
  • Chaque compte dispose d'un realm Keycloak dédié assurant une isolation multi-tenant complète.
