Services Professionnels OPCP

Débutant

Présentation

Après le déploiement de votre plateforme OPCP sur site et la réception de vos identifiants d'accès, quelques étapes de configuration sont nécessaires avant que votre environnement soit pleinement opérationnel.

OPCP est une plateforme sur site (on-premise) — elle fonctionne dans vos propres locaux. Après le déploiement, vous vous connectez via l'URL définie lors de la livraison et vous authentifiez via la page Keycloak pour accéder au tableau de bord.

Référence : Documentation OVHcloud OPCP — Premiers pas

Étape 1 : Explorer le Tableau de Bord Horizon

Une fois connecté via Keycloak, vous accédez au tableau de bord OpenStack Horizon — l'interface principale pour gérer votre infrastructure OPCP. Le tableau de bord donne accès aux services de votre plateforme : IAM (Keycloak) pour la gestion des utilisateurs, et les API OpenStack (Keystone, Glance, Nova, Neutron, Ironic).

Sections clés à explorer :

  • Projet > Vue d'ensemble — Consultez vos limites de quotas : Compute (instances, vCPUs, RAM), Réseau (IP flottantes, groupes de sécurité, réseaux, ports)
  • Projet > Accès API — Liste les 10 services disponibles avec leurs URLs de endpoints
  • Compute > Instances — Lister et gérer vos serveurs bare metal dédiés
  • Compute > Images — Images OS disponibles pour le déploiement
  • Réseau > Réseaux — Liste des réseaux disponibles
  • Réseau > Topologie — Représentation visuelle de votre architecture réseau

Important : Les images OS doivent correspondre aux pilotes matériels (pilotes bare metal, pas les pilotes virtuels qemu/kvm).

Étape 2 : Comprendre Vos Quotas

Votre plateforme OPCP dispose de quotas de ressources définis, visibles dans Projet > Vue d'ensemble. Ils définissent les limites de ce que vous pouvez déployer :

  • Quotas Compute — Nombre maximum d'instances, de vCPUs et allocation RAM
  • Quotas Réseau — Maximum d'IP flottantes, groupes de sécurité, réseaux et ports

Ces quotas représentent la capacité physique de votre baie sur site. Si vous devez les ajuster, contactez votre représentant OVHcloud.

Étape 3 : Configuration Réseau

La configuration réseau dans OPCP est pilotée par Horizon/API (Neutron). Une caractéristique clé de la plateforme est que les switchs réseau sont automatiquement configurés à partir des informations que vous définissez dans OpenStack.

Cela signifie :

  • Vous définissez les réseaux et ports dans Horizon ou via l'API Neutron
  • La configuration physique des switchs est appliquée automatiquement — pas de configuration manuelle des switchs nécessaire
  • Les VLANs et ports trunk sont gérés via la couche d'abstraction OpenStack

Naviguez vers Réseau > Réseaux pour voir les réseaux disponibles, et Réseau > Topologie pour une vue d'ensemble visuelle de votre architecture réseau.

Étape 4 : Gestion des Clés SSH

Avant de déployer des instances, configurez vos clés SSH pour un accès sécurisé aux nœuds bare metal :

  • Naviguez vers Compute > Paires de clés
  • Importez votre clé publique SSH existante ou créez une nouvelle paire de clés
  • Les paires de clés seront injectées lors du provisionnement des instances pour un accès sécurisé

Étape 5 : Accès Utilisateurs via Keycloak

La gestion des utilisateurs dans OPCP est assurée par le service d'identité Keycloak embarqué (IAM). Accédez à Keycloak depuis le tableau de bord pour :

  • Créer des comptes utilisateurs pour les membres de votre équipe
  • Définir des rôles et des permissions
  • Optionnellement intégrer avec LDAP/Active Directory (TCP/636 LDAPS) pour une gestion centralisée des identités

Trois niveaux d'accès sont typiquement configurés :

  • Administrateur — Accès complet à tous les paramètres et services
  • Opérateur — Peut gérer les services et déployer des instances
  • Lecture seule — Peut consulter les informations mais ne peut pas effectuer de modifications

Configuration Terminée

Une fois ces étapes accomplies, votre environnement OPCP est prêt pour le déploiement d'instances bare metal. Voici un récapitulatif rapide :

  1. Exploration du tableau de bord Horizon et compréhension des services disponibles
  2. Vérification de vos quotas de ressources (Compute et Réseau)
  3. Compréhension de l'auto-configuration des switchs réseau depuis OpenStack
  4. Configuration des paires de clés SSH pour l'accès sécurisé aux instances
  5. Configuration des accès utilisateurs via Keycloak IAM

À partir d'ici, vous pouvez explorer la section Cycle de Vie des Nœuds pour comprendre la gestion des nœuds bare metal, ou passer aux Opérations Techniques pour déployer votre première instance.
