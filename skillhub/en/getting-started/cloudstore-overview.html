The Secure Warehouse Analogy

Imagine your business generates mountains of documents, photos, videos, and data files every day. Where do you keep all of it?

Think of CloudStore as a secure, expandable warehouse for your digital assets — located right inside your own building. Just like a professional storage facility:

  • It grows with you — need more space? Simply request additional room. No construction required.
  • It's always accessible — authorised staff can retrieve items anytime using standard S3-compatible tools.
  • It's professionally managed — the facility handles security, maintenance, and availability. You focus on your business.
  • Your items stay on-site — data never leaves your premises, ensuring full sovereignty.

CloudStore is OVHcloud's S3-compatible object storage service within the OPCP platform. It runs locally on your on-premise OPCP rack, letting you store, organise, and retrieve any type of digital data using the standard S3 API (AWS SDK compatible) — without your data ever leaving your site.

How CloudStore Works

Common Use Cases

CloudStore is versatile enough to handle many different business needs. Here are the most common scenarios:

Document Storage

Store contracts, reports, spreadsheets, and presentations in a central location accessible to your entire team. Think of it as a shared filing cabinet that never runs out of drawers and can be accessed using any S3-compatible tool.

Media Archives

Keep large collections of images, videos, and audio files safe and organised. Marketing teams, creative agencies, and media companies use CloudStore to maintain their growing libraries without worrying about running out of space.

Application Data

Software applications generate data constantly — user records, transaction logs, configuration files. CloudStore provides a reliable home for this data via the S3 API, ensuring applications can read and write information quickly and safely.

Backups

Create safety copies of your critical business data. If something goes wrong with your primary systems — hardware failure, accidental deletion, or a security incident — your backups in CloudStore let you recover quickly, all without data leaving your premises.

OPCP-Specific Characteristics

CloudStore on OPCP has specific characteristics that differentiate it from the public cloud S3 offering. Understanding these helps you advise customers accurately:

  • MonoAZ only — CloudStore operates in a single availability zone (your on-premise rack). There is no multi-AZ configuration.
  • Standard storage class only — Only the "Standard" class is available. There is no "High Performance" class on OPCP.
  • SSE-C encryption — Server-Side Encryption with Customer-provided keys is supported. The client manages and provides the encryption key with each request. There is no at-rest encryption by default.
  • Versioning via API — Object versioning is supported and managed through the S3 API.
  • No user policies — All access keys can access all buckets. There are no per-user bucket restrictions available.
  • No metadata API endpoint — The metadata endpoint is not available on OPCP.
  • S3-compatible API — Fully compatible with AWS SDKs and standard S3 tools.
  • Local buckets — All buckets are local to the OPCP platform, stored on-premise at the customer site.

Official documentation: For a complete list of limitations and supported features, refer to the S3 OPCP limitations guide.

Why Customers Choose CloudStore

  • Full data sovereignty — Data stays on YOUR premises, in your own rack. It never transits through external data centres.
  • S3 compatibility — Use existing tools, SDKs, and workflows built for S3 without modification.
  • On-premise performance — Local storage means low-latency access without internet dependency.
  • No hardware management — OVHcloud manages the infrastructure within your rack.
  • Compliance ready — Meet strict data residency requirements since data physically remains on-site.
  • Scalable capacity — Storage grows with your needs within the rack's physical capacity.

Key Takeaways

  • CloudStore is an S3-compatible object storage service running locally on your OPCP rack.
  • It handles documents, media, application data, and backups using the standard S3 API.
  • Data never leaves your premises — full sovereignty and compliance by design.
  • Key limitations: MonoAZ, Standard class only, SSE-C encryption (no at-rest by default), no user policies.
  • Compatible with AWS SDKs and any S3-compatible tooling.
