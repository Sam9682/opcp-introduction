Utilisation des API & Gestion des Identifiants

Intermédiaire

Présentation

OPCP expose des API OpenStack standards pour gérer votre infrastructure bare metal sur site de manière programmatique. Ces API sont accessibles depuis l'onglet Projet > Accès API dans le tableau de bord Horizon, qui liste tous les endpoints de services disponibles.

En plus des API OpenStack, OPCP fournit des outils CLI dédiés pour la gestion de la plateforme et les diagnostics.

Référence : Documentation OVHcloud OPCP — Premiers pas

API Disponibles

OPCP donne accès aux API de services OpenStack suivantes :

Service API Fonction
Identité Keystone Authentification, autorisation et catalogue de services
Compute Nova Gestion du cycle de vie des instances (serveurs)
Image Glance Gestion et découverte des images OS
Réseau Neutron Gestion des réseaux, sous-réseaux, ports et groupes de sécurité
Bare Metal Ironic Cycle de vie et provisionnement des nœuds bare metal

Toutes les URLs des endpoints sont visibles dans Projet > Accès API du tableau de bord Horizon.

Outils CLI

OPCP fournit plusieurs outils en ligne de commande pour la gestion de la plateforme :

opcp-cli

L'outil CLI principal pour la configuration et les opérations OPCP :

  • Déclarer et gérer les ressources de la plateforme
  • Configurer les composants de la plateforme
  • Effectuer des tâches opérationnelles (configuration LACP, etc.)

L'accès se fait via le réseau de gestion OOB (Out-of-Band).

opcp-diag

Outil de diagnostic pour l'évaluation de l'état de la plateforme :

  • Produire un rapport d'état de santé de la plateforme
  • Extraire les logs pour un diagnostic à distance par le support OVHcloud

python-ironicclient

Pour la gestion directe des nœuds bare metal via CLI :

# Installer le client Ironic
pip install python-ironicclient

# Lister les nœuds bare metal
openstack baremetal node list

# Afficher les détails d'un nœud
openstack baremetal node show $NODE_ID

# Gérer les transitions d'état des nœuds
openstack baremetal node manage $NODE_ID
openstack baremetal node provide $NODE_ID

Accéder aux API

L'accès aux API dans OPCP suit le flux d'authentification OpenStack standard :

Flux d'Authentification

  1. Obtenir un token — S'authentifier auprès de Keystone avec vos identifiants (gérés via Keycloak)
  2. Découvrir les endpoints — Le catalogue de services retourné par Keystone liste tous les endpoints API disponibles
  3. Effectuer des appels API — Utiliser le token pour authentifier les requêtes vers Nova, Neutron, Glance ou Ironic

Via le Tableau de Bord Horizon

Naviguez vers Projet > Accès API pour :

  • Voir toutes les URLs des endpoints de services
  • Télécharger le fichier OpenStack RC (openrc) pour l'authentification CLI
  • Accéder au catalogue de services

Via la Ligne de Commande

Sourcez le fichier OpenRC et utilisez le CLI OpenStack standard :

# Sourcer vos identifiants
source openrc.sh

# Vérifier l'authentification
openstack token issue

# Lister les services disponibles
openstack catalog list

Gestion des Identifiants

Les identifiants dans OPCP sont gérés via Keycloak (le service de gestion des identités et des accès embarqué) :

  • Comptes utilisateurs — Créés et gérés dans Keycloak
  • Rôles et permissions — Définis au niveau projet/domaine dans Keystone
  • Intégration LDAP/AD — Connexion optionnelle à des fournisseurs d'identité externes (TCP/636 LDAPS)
  • Identifiants d'application — Peuvent être créés dans Keystone pour l'authentification service-à-service

Rotation des Identifiants

La rotation régulière des identifiants est recommandée :

  • Comptes administrateurs — Rotation tous les 30 à 90 jours
  • Comptes de service — Rotation tous les 90 à 180 jours
  • Identifiants d'application — Définir des dates d'expiration appropriées à la création

Points Clés à Retenir

  • OPCP utilise les API OpenStack standards — Keystone, Nova, Glance, Neutron et Ironic
  • Tous les endpoints API sont listés dans Horizon sous Projet > Accès API
  • opcp-cli est utilisé pour la configuration de la plateforme et la déclaration des ressources
  • opcp-diag fournit les diagnostics de santé de la plateforme et l'extraction des logs
  • python-ironicclient permet la gestion CLI des nœuds bare metal
  • L'authentification est gérée via Keycloak avec intégration LDAP/AD optionnelle
  • Toute la gestion se fait via le réseau OOB (Out-of-Band)
